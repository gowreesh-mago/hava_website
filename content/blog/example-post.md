This file is a template and is not published because of `draft: true`.

To add a post:

1. Copy this file to `content/blog/YYYY-MM-DD-short-title.md`.
2. Set `title`, `date`, `author` and a one-sentence `description` (shown in the list and in link previews).
3. Delete the `draft: true` line.
4. Write the post below the front matter in Markdown. Images go in `static/images/` and are embedded as `![caption](../../images/file.jpg)`.
